`named-silent` = a truthful empty answer or named failure (e.g.
Media Foundation EOS with no frames, Steam auth-only answers).
The [title matrix](title-matrix.md) tracks observed gameplay separately.

delay-load directory (e.g. `UnityPlayer.dll -> d3d12.dll`,
`binkw32.dll -> mss32.dll`); they are also folded into the class counts
and the total, matching the loader's eager delay binding.
