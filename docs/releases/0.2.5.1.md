# Tiramisu 0.2.5.1

This release carries forward the Xbox storage and runtime improvements from
0.2.5.0 and adds the recovered dashboard preview, PE64 loader changes, and
D3D11 render diagnostics that were absent from that package.

## What changed since 0.2.5.0

- **Standalone dashboard preview.** The recovered app includes the game
  library, controller navigation, settings, and game and mod views. The
  preview works with sample data in the browser. The Xbox app's live LAN
  dashboard remains available on port 9127. The preview ships separately as
  `Tiramisu-Dashboard-Preview.zip`. [Dashboard guide](../../apps/dashboard/README.md)
- **Circular PE64 DLL dependencies.** The loader stages the dependency graph,
  resolves back-edge exports from pending images, and protects the mapped
  images before TLS and process-attach callbacks. Qualified loads continue
  to distinguish files that share a basename. The loader regression tests
  mutual imports, missing back-edge exports, and rollback when image
  protection fails.
- **D3D11 target diagnostics.** The render report now counts draws using the
  current virtual backbuffer, a retired backbuffer, or an untagged resource.
  It also reports RGB writes disabled by the blend state and a zero sample
  mask. These counters help locate black-frame failures.
- **Public documentation.** The setup tutorial covers USB, Device Portal,
  and LAN transfers. Contributor docs use the compatibility and setup guides
  directly. The internal prompt and work map files were removed from the
  current tree.

## Cumulative changes over the previous public builds

0.2.5.0 included automatic USB discovery, Device Portal folder and ZIP
imports, on-demand DLL loading from mounted images, launch profiles with
dependency evidence, PE32 compatibility, Steam install readiness, expanded
Windows API and middleware coverage, and input, graphics, and Xbox model
profiles. Those changes are also present here.
[Complete 0.2.5.0 changes and file inventory](0.2.5.0.md) ·
[Source comparison from 0.2.4.12](https://github.com/xanstomper/Tiramisu/compare/v0.2.4.12...v0.2.5.1)

Recent worktree and capture comparisons found earlier versions of loader,
transfer, managed-host, and module-path fixes already represented by their
later integrated equivalents. Old diagnostic package variants and saved
working copies follow their own test and build histories. The release
packages use the current source together with the changes above.

## Downloads and verification

- Use `Tiramisu.msix` with `dev.cer` for the standard edition.
- Use `Tiramisu-EdgeSpoof.msix` with `edge-dev.cer` for the experimental
  hardware keyboard and mouse edition.
- For the standalone dashboard, extract `Tiramisu-Dashboard-Preview.zip` and
  run `python3 -m http.server 8080 --bind 127.0.0.1` in the extracted folder.
  Open `http://127.0.0.1:8080` in your browser.
- Use `SHA256SUMS` to verify the downloads.

The Linux suite includes the circular-import regression. Both Xbox MSIX
packages are signed with the previous release's certificates and checked for
matching host binaries. The dashboard passed its type, logic, and production
build checks. On-console gameplay and a physical USB hot-plug test on this
exact package remain open.
